# PetCast 第一轮宠物动画素材

日期：2026-10-25。使用内置 imagegen，参考项目当前五只宠物的 PNG 制作；未覆盖原有角色素材。

本轮包括猫、狗、鸡、兔子、鲨鱼。每只提供 4 帧待机与 8 帧移动；猫狗鸡行走、兔子轻跳、鲨鱼游动。角色保持原有朝向。反向移动可在程序中水平翻转；鲨鱼只在河中活动，其他角色只在沙地活动。

## 文件

- `raw/`：内置 imagegen 生成的透明 PNG 原图。
- `sheets/`：按完整角色轮廓整理后的规则图集，每只 4 列 × 3 行。
- `frames/`：60 张独立透明 PNG 帧。整理过程仅做整体平移与排列，完整保留像素和透明度，不逐帧缩放或重画角色。
- `previews/`：便于查看的循环 GIF。
- `preview.html`：可播放的五宠动画预览，包含待机、移动、方向与播放速度控制。
- `manifest.json`：原始图集尺寸、网格位置、帧边界和建议时长。
- `prompts.json`：全部生成提示词、角色参考路径和布局规格。
- `corrections.json`：兔子画布留白修正的生成提示词与参考图。
- `validation.json`：透明度、帧数、裁切边界和可打开性检查结果。

## 帧顺序

图集第一行为 4 帧待机。第二、三行按从左到右、从上到下组成 8 帧移动。所有行列均从零开始计数。

原始生成图集的帧间距并不完全规整，因此按透明轮廓识别完整角色后重新排布，避免按原始网格切断脚尖或尾巴。帧宽高以 `manifest.json` 为准，同一角色的 12 帧画布严格一致。所有正式导出帧都保留至少 24 像素透明安全边距。兔子轻跳包含少量整体抬升；其他角色统一落点。

动画预览用于检查角色一致性与循环效果。素材现已接入主页活动；小屋与形象页使用另存的安静呼吸素材，详见项目 `docs/C_PET_ANIMATIONS.md`。透明 PNG 是后续接入程序的正式源素材，GIF 仅用于查看。
