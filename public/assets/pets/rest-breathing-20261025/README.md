# PetCast 安静待机与呼吸素材

2026-10-25。猫、狗、鸡、兔子的静坐姿势使用内置 imagegen 参考原有形象生成；鲨鱼保留原始形象，在水中停留。

- 胸腹部局部变化，头部、眼睛、耳朵上部与脚底保持原位；不额外眨眼、摆尾、行走或上下漂浮。
- 每只 16 个呼吸采样帧，4.8 秒一轮；幅度在 256 像素画布中不超过 2.1 像素，实际程序显示时更轻微。
- 原始姿势见 `bases/`，透明图集见 `sheets/`，独立帧见 `frames/`。
- `native/` 是程序使用的循环 PNG 动画及静态首帧。`-idle.png` 为呼吸，`-move.png` 为上一轮确认的行走或游动；`-still.png` 供减少动态效果时显示。
- 内置 imagegen 生成提示词在 `prompts.json`，动画渲染检查在 `render-validation.json`，资源尺寸和时长在 `manifest.json`。

图片动画不写入游戏、额度或历史存档。主页的移动范围、换向间隔及随机休息由单独的视觉状态逻辑处理。
