# PetCast

一款使用 Electron、React、TypeScript 与 Vite 构建的 AI 额度桌宠与轻量收集游戏。目前已进入 Stage 7：在前六阶段玩法之上加入本地存档与恢复。

## 运行

```bash
pnpm install
pnpm dev
```

生产构建后运行：

```bash
pnpm build
pnpm start
```

浏览器演示：

```bash
pnpm build
node .\node_modules\vite\bin\vite.js preview --host 127.0.0.1 --port 4173
```

## 已完成的桌宠与演示功能

- 无边框、置顶、透明窗口
- 使用提供的 Blåhaj 8 × 9 WebP 精灵图（192 × 208 像素/帧）播放待机与拖动动画
- 自定义窗口拖动、左右方向动画与拖动反馈
- 同一窗口展开河边占位场景
- 折叠后恢复紧凑窗口尺寸与位置
- `UsageProvider` 数据抽象和 `MockUsageProvider`
- 5h 额度、周额度、两类重置时间、消耗速度与基准速度
- 额度状态分析、周节奏判断和行动建议
- 紧凑额度看板与点击布罗艾出现的提醒气泡
- 六种额度演示预设和可调额度控制台
- 布罗艾随健康、紧张、疲惫、重置状态切换动画
- 像素风动态河流：消耗速度控制流速，周额度剩余控制水位
- 河边场景跟随系统时间切换白天、晨昏与夜晚
- 额度重置触发一次潮汐亮起反馈
- 河岸像素小屋、邮箱与可点击钓鱼入口
- 4种使用习惯鱼与基于当前习惯的加权生成
- 抛竿、随机咬钩、限时收竿、失败重试和捕获快照
- 捕获成功即永久点亮图鉴，并记录捕获、喂食和放生次数
- 钓获后的保留、喂给布罗艾、放生三种处理方式
- 可点击进入的像素小屋、墙上图鉴与鱼类详情
- 固定容量 4 的动态水族箱，鱼会左右游动并可点击查看个体数据
- 水族箱满时选择旧鱼替换，并决定喂食或放生
- 喂食后的布罗艾开心动画和专属气泡台词
- 可替换的 `ResetSignalProvider` 与离线数据实现
- 启动时自动投递 Tibo 重置预告，布罗艾显示信封，河边邮箱显示未读标记
- 重置消息链接到指定的真实 X 原帖，并由 Electron 安全地交给系统浏览器打开
- 邮箱会把外部重置线索与当前 5h / 周额度、预计恢复倒计时交叉核对，并明确区分“预告”与“已确认重置”
- Mock 演示中倒计时到期后自动恢复额度、播放河流效果，并生成模拟重置记录；真实模式必须查询确认
- 额度控制台提供“立即到点”，可在展示时直接验证完整重置闭环
- 每 10 分钟检查重置动态，支持暂停、立即检查、检查中与失败反馈
- 同一 X 帖子按稳定 ID 去重，不会重复塞满邮箱
- 邮箱支持“全部 / 重置线索 / 钓鱼报告”分类，最多保留 30 条消息
- 自动钓鱼开关、立即钓鱼、下次运行倒计时及每 5 分钟后台运行
- 每次自动钓鱼生成 3 条鱼，自动更新图鉴并生成邮箱报告
- 自动捕获的鱼会放生，不占用水族箱容量
- 额度状态进入紧张、加速或重置阶段时会主动出现气泡提醒，并避免同状态重复打扰
- Electron 使用用户数据目录中的 JSON 存档，浏览器演示使用 localStorage
- 自动保存并恢复水族箱、图鉴、邮箱、未读消息、模拟额度状态及自动功能开关（真实余额每次重新读取）
- 存档经过版本和字段校验；损坏存档会被隔离并安全回到默认状态
- 控制台显示“读取 / 保存 / 已保存 / 失败”状态
- 任务分析支持 Prompt 和文件元信息输入，并可识别任务类型与复杂度
- 任务分析支持 Token 区间启发式估算、Prompt 优化以及串行/并行任务建议
- `TaskAnalysisPanel` 已接入主程序，支持文件选择、结果展示和结构化错误提示

## A：真实 Codex 额度模块

首版读取每位用户自己电脑上已登录的 Codex，不绑定开发者账号。通过官方 Codex App Server 的只读账号接口获取 5 小时 / 周额度和重置时间；不需要用户把登录文件或 API Key 交给 PetCast。

- 已完成：自动查找 Codex、主进程读取、受限 IPC、Provider、明确的真实 / 模拟工厂、定时刷新、取消、失败与账号隔离、消耗速度计算。
- 已验证：自动化测试、TypeScript 检查、生产构建，以及 Windows 本机真实账号读取。
- 主页面已接入真实额度：紧凑窗口点击“额度设置”，展开后在右侧切换来源、重新读取；选择会保存在本机。未登录或首次读取失败显示“额度未知”，不会显示模拟余额。
- 失败后保留的旧快照会标明采样时间，并暂停额度提醒、重置效果和钓鱼。退出登录或无法验证身份时清空余额；旧模拟存档只恢复到模拟模式。
- `npm run test:ui` 可运行无网络的页面验收；`node scripts/smoke-desktop.mjs --codex` 验证本机真实读取到页面。尚未完成其他用户电脑验收及成品安装包。
- `burnRate` / `baselineBurnRate` 现在允许 `null`，表示数据不足。已有分析、钓鱼和存档已适配；D 的历史字段同步允许 `null`。

开发者可在已登录 Codex 的电脑运行：

```bash
pnpm check:codex
```

它仅输出额度及时间，不输出账号身份或凭据。详细运行方式、接口与接入清单见 [A 模块接入说明](docs/A_CODEX_USAGE.md)。
