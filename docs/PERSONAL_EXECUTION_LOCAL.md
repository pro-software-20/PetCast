# 个人账户与整组执行（本地更新）

基于 main 7082bd6。本地更新尚未发布或上传 GitHub。

## 试用路径

1. 进入任务分析，先选择 DeepSeek 大脑，在出现的账户表单中填写自己的 DeepSeek API Key 和模型名称，点击“检测并连接我的账户”。
2. 检测只查询官方模型列表，不产生任务推理；通过不保证余额充足。密钥只保留在当前 Electron 主进程内存中，不进入任务记录、localStorage、日志或导出，退出应用后须重新连接。
3. 点击开始分析。已连接时，任务拆解直接使用个人账户，不发送到团队规划服务；前置 Prompt 优化使用本地规则。未连接时明确回退本地规则，不产生远程请求。Codex 大脑也可在同一位置选择并连接，参见 CODEX_QUEUE_LOCAL.md。
4. 方案生成后，在“这组任务怎么执行”中点击“将适合的任务统一设为 DeepSeek 自动执行”。该操作只改计划，不调用模型。已开始的任务与要求文件、软件操作的任务保留原方式，并列出原因。
5. 检查自动协调队列，点击启动并确认。DeepSeek 返回结果后进入待验收；按原流程确认结果后，依赖任务解锁。暂停、取消、结束与暂存仍沿用已有恢复机制。

## 已验证与边界

- 单元验证覆盖批量设置、不改已开始任务、保留文件操作任务、无效密钥与模型、凭据不落盘、个人规划结构校验和预取消。
- 隔离桌面测试覆盖缺少账户时禁用、填写模拟账户、清空密码框、整组设置、不自动派发及原有协调/恢复/验收流程。
- 未取得真实个人 API 账户，未完成个人账户真实端到端验收。此前团队规划服务真实请求通过不代表个人执行通过。
- 另已新增 Codex 统一文本执行适配器；没有新增网页自动化，不能自动控制任意已登录软件。
- 最终验收仍为人工；没有将未经检查的 AI 回答自动标为合格。全自动主控复核、返工与多软件接力仍需单独实现和真实验证。
- API 批量适配只适用于文本任务，是保守筛选，不是通用软件能力证明。应由用户确认计划、费用和执行范围。
- 规划阶段真实 Token 账本写入、账户长期加密保存、多账户管理不在本次实现中。
