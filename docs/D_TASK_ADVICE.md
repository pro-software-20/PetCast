# D v5：任务建议与综合推荐已接入

## 当前行为

任务建议是本地、确定性的规则结果，不需要额外 AI 调用。入口：河边 → 使用历史与报告 → 任务使用建议。每条包含标题、观测依据、行动、局限及关联任务 ID。

- 输入来自所选区间、当前来源和账号的结束任务。真实 / 模拟 / 账号隔离，重复记录不增加证据。
- 同页适配器写入 / 清除后刷新；跨标签页存储变化刷新。报告可见时每 30 秒补查，恢复可见时重读。建议不用等待下一次额度变化。
- 无记录、实际用量不全、缺少可比模型证据都明确解释，不用分析估计填补真实用量。
- 先显示 6 条，再展开更多；故障与明显变化优先。用户导入数据额外说明未经服务商核验。

## 规则与证据

| 类型 | 触发条件 | 建议 |
| --- | --- | --- |
| 重试 / 失败 | 存在 status=failed 或 attempt>1 的调用，两者并集避免重复计数 | 查看服务状态 / 结果，确认后有上限地重试；不推断具体失败原因 |
| 输入占比 | 全部调用都有实际 usage，输入 ≥1000 Token 且占总量 ≥80% | 检查重复资料、去除无关上下文，保留必要信息；不认定高输入就是浪费 |
| 输出占比 | 全部调用都有 usage，输出 ≥2000 Token 且占比 ≥70% | 需要时约定篇幅、先提纲后展开；不盲目削减必要结果 |
| 同类变化 | 此前至少 3 个同类、同模型组合的成功完整计量任务，最多取最近 20 个；本次 Token 或耗时 ≥历史中位数的 2 倍 | 检查任务规模、重复输入、等待等；独立子任务可考虑分批，不承诺更省 |
| 模型试用 | 同一 category / comparisonKey / 评价方法及标准版本；每模型 ≥3 个已评价任务，全部成功且达标；所有调用有同币种实报费用；候选费用中位数至少低 20%，耗时中位数不高于原模型 1.25 倍 | 建议下次相似任务小范围试用，并确认权限、当前价格和可用额度；不自动改模型优先级 |

失败重试 Token 只合计有 usage 的调用并显示覆盖数量。模型建议的“达标”来自用户或执行器评价，非系统自行验证；未评价任务不参与比较。模型费用只用 provider-reported，不将 price-estimate 当成实际省钱证据。没有证据时解释缺少什么。

这些是待试用校准的产品门槛，不是统计显著性检验；任务规模和用户选择可能影响比较结果。报告并不自动分析任务正文、评判结果质量或确认某段 prompt 重复。

## 待执行任务的综合推荐

已补齐同一待办任务的模型 + 时间统一决策与页面。综合推荐使用独立近 30 / 90 天历史和最新事后评价，先筛模型能力、质量、实际消耗、截止时间和资源约束，再按优先级比较费用、完成时间及模型偏好；详见 [综合推荐说明](D_UNIFIED_PLAN.md)。

## 独立的额度等待时间建议

页面使用 A 当前账号的新额度（非历史报表额度），用户填写截止时间、预计分钟、预计短周期百分点、预计周额度百分点和是否紧急。截止时间输入按本机时区解释，预算是估计值；未知留空，不默认填零。

决策顺序：

1. 校验任务作用域、日期、正耗时和两种 0–100 额度预算。
2. 安全余量为 max(10 分钟, 预计耗时 ×20%)；现在就来不及时提示调整范围 / 截止时间。
3. 额度必须 fresh、同账号，采样不超过 5 分钟且不能在未来；否则先刷新。
4. 两种窗口都覆盖预算时，无需仅为刷新而延期。
5. 至少一个窗口不足且任务紧急时，不建议自动延后。
6. 不足窗口的恢复时间必须有效且在未来，多个不足窗口取最晚恢复时间。
7. 恢复时间 + 预计耗时 + 安全余量早于或等于截止时间，才建议“可等待后重新读取”。否则提示等待可能赶不上。

到达恢复时间也不代表额度已恢复。建议始终要求重新读取、确认预算，再由用户决定执行。不创建任务队列、自动定时运行或提醒，也不从历史额度推断任务真实截止时间。

## 接入边界

任务建议规则、页面、自动刷新、质量评价字段及时间建议函数已实现。执行模块仍需将真实调用和评价写入账本；这不是 D 还缺建议逻辑。没有真实数据时，模拟页可演示建议，真实页说明数据不足。

TaskExecutionRecorder.finish(status, quota, evaluation) 可一次写入可选评价；旧文件无需迁移。执行器也可直接写完整 TaskRecord，详见 D_TASK_LEDGER.md。

验收命令：npm run test:contracts；npm run build；node scripts/test-history-ui.mjs。自动测试覆盖少样本、缺失用量、未来历史、不同账号、失败重试并集、模型质量 / 币种 / 来源门槛、紧急任务、截止冲突、双窗口约束与过期额度。页面测试用独立临时记录验证自动更新和清除，不发起真实模型调用。

历史复盘建议仍按报告区间计算；待办综合推荐在独立区域查询近期历史。两者不要混用。新评价字段、模型指定和可选当前价格估算见 D_UNIFIED_PLAN.md 与 D_TASK_LEDGER.md。
