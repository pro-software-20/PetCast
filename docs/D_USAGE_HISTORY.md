更新日期：2026-10-22。基于已合并 PR #2 的 main `52714ab8383afce0562ebad0967720d335dc7ee5`；未上传 GitHub，未覆盖组员分支。入口：河边 → 使用历史与报告。

## 周期与展示

- 周报默认周一至周日，可独立设置开始 / 结束星期。止日包含全天；周五至周四表示跨周，周一至周五表示工作日窗口，同一星期表示单日。按“所在周日期”定位最近的开始星期，设置自动保存。
- 月报默认当前自然月，可选择其他月份。周报 / 月报都可手动改起止日期，再点“恢复本周 / 月”恢复默认。临时自定义日期不作为下次启动默认。
- 显示所选时区的明确起止时间；日期止日转换为次日开始的半开区间。当前周期只统计到现在，未来区间、反向日期和超长区间显示错误。支持跨年、闰年和 DST。
- 周报侧重本期节奏和行动建议；月报额外按每 7 个日期显示月内分段消耗、覆盖和速度。每日柱状图和 24 小时时段图均显示缺失；小时图按有效观测时长归一，悬停查看速度、时长和覆盖日期。
- 上期比较：周报使用前一周相同跨度，月报使用前一个自然月，自定义区间使用前一段相同经过时长；当前周期未结束时，只取上期对应已过去时长（按实际毫秒，DST 的本地钟点可能不同）。较短月份截断到月底。
- 两期都达到习惯证据门槛、覆盖时长比在 0.5–2、小时覆盖分布重叠至少 70%，才显示平均速度变化。零基数不算百分比；不比较未经校正的消耗总量，不把速度当成效率。

## 真实统计与规则建议

只记录 A 提供的 fresh 快照，通常每 3 分钟一条；窗口变化、压力边界或额度回升提前补记。回升前的最近观测也保存，防止掩盖恢复过程。source + scopeId + sampledAt 去重。写入失败不推进成功位置，下次有效读取重试。

相邻片段必须间隔不超过 5 分钟、两种重置时间不变、两种额度未增加。其余断开，不算跨段消耗。平均速度按时长加权，峰值取有效片段最大值。有效片段没有消耗可记零，没有有效片段记 null。短周期百分点可跨刷新周期累计超过 100，不能换算 Token / 金额。

低额度阈值仍是短周期 25%、周额度 22% 的产品提示规则，不是平台官方限制。报告同时显示跨入次数和持续时长；时长按有效片段线性插值估算，初次已经低额度也能累计。小时 / 日期分桶按片段均匀消耗估算，不声称是精确调用时间。

删除报告中低于 10 为保守、10–20 为均衡、高于 20 为偏快的固定评价。使用建议来自：有效记录的日期和时长、低额度时长与次数、有足够覆盖的小时段消耗速度。任务建议现已接入账本，详见 D_TASK_ADVICE.md；页面支持为同一个待办任务联合推荐模型与时间，结合质量评价、实际消耗、截止时间、任务优先级和当前资源，见 D_UNIFIED_PLAN.md；独立的额度等待评估也保留。未提供任务期限 / 执行预算时不虚构排期，不自动执行。

习惯证据门槛为至少 3 个有效日期（每天 ≥30 分钟）、合计 ≥6 小时；小时段提示还要求该小时覆盖 ≥3 天且 ≥1 小时。这是待真实用户试用校准的规则，不是统计学置信度，也不表示观测到了用户全天行为。当前建议不调用大模型。

趣味称号：

| 名称 | 规则（均先满足习惯门槛，且确有消耗） |
| --- | --- |
| 足迹收藏家 | 至少 7 个日期有 ≥30 分钟有效覆盖和实际观测消耗，不要求连续打卡 |
| 晨光搭档 | 已观测消耗至少 60% 在 06:00–12:00 |
| 日光同行者 | 未满足晨光搭档且至少 80% 在 08:00–20:00 |
| 余粮守护者 | 至少 7 个有效日期，记录片段内没有低额度持续时间 |

称号按所选报告区间计算，显示依据；不作为永久成就档案，不奖励高消耗或熬夜。月报示意的称号和任务从不写入真实记录。

## 存储、容量与隔离

桌面额度历史：Electron userData 下 `petcast-usage-history-v1.json`。保留版本 1，旧记录直接兼容；每账号 / 来源最多 90 天、100,000 条（原上限 20,000 已提高）。3 分钟常规采样 90 天约 43,200 条，足够正常情况下相邻两月对比。旧版本已经清理的历史无法恢复。频繁额外事件、应用未运行或容量不足仍可能造成记录不全，不承诺完整账单。整个文件上限 128 MB，写入前检查，超限保留原文件并报错。

桌面任务账本：`petcast-task-ledger-v1.json`；每作用域 180 天 / 10,000 个结束任务，文件上限 64 MB，最多 100,000 个任务总记录。详情见 `D_TASK_LEDGER.md`。

两种文件均独立于游戏存档。固定命名 IPC、主窗口 / 主 frame / 地址校验、主进程单实例与串行写入、临时文件原子替换。坏文件读错误不能变成空数组，追加和清除也不覆盖坏文件。

浏览器分别使用 `petcast.usage-history.v1` 和 `petcast.task-ledger.v1`；支持 Web Locks 时协调多标签页，否则只保证同实例串行。浏览器受站点容量限制，容量不足可报错，长期使用以桌面文件模式为准。不会把未采集时间补成零，不采集应用 / 网站活动，不保存账号凭据。

额度历史、任务账本分别确认清除，仅影响当前来源 / 账号。退出登录和切换账号时隐藏旧报告。匿名 scopeId 必须由 A 提供，不自行使用邮箱、Token 或 Cookie。
