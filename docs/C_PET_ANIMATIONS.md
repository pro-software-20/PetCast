# PetCast 宠物动画与主页活动

2026-10-25。本地分支：`features/c-outlook`。

## 最终行为

- 主页猫、狗、鸡在沙地行走，兔子轻跳，鲨鱼在水域游动。活动仅沿水平方向进行，保持已确认的沙地/河流位置与安全范围。
- 各段活动约 8.5–16.5 秒，结束后随机停留 5–10 秒；左右朝向随移动方向水平翻转，换向间隔至少 18 秒。接近边界且尚未到换向时间时继续休息。
- 停留时使用安静待机：陆地宠物静坐，鲨鱼留在水中；只在胸腹部表现轻微呼吸，不额外眨眼、摆尾或上下漂浮。
- 小屋和形象页的角色保持呼吸待机。形象选择小卡片与外壳缩略预览用静态首帧，当前形象大预览与缩略窗口可显示呼吸。
- 打开小屋、形象、额度、任务、历史或钓鱼面板时，主页背后的宠物停止活动。隐藏窗口时暂停计时，恢复后先休息，避免大跨度追赶或跳位。
- 系统选择减少动态效果时，停止活动并显示静态首帧。

## 素材

- `public/assets/pets/animations-20261025/`：上一轮确认的五宠动作图集与逐帧素材。
- `public/assets/pets/rest-breathing-20261025/`：新静坐姿势、轻微呼吸帧与运行时循环 PNG。
- 陆地动物的新姿势使用内置 imagegen，提示词见素材目录 `prompts.json`；鲨鱼沿用原始形象。胸腹部呼吸通过固定图像的局部动画渲染生成，已检查头部与脚底在各帧中保持不变。
- 每只 16 个呼吸采样帧，4.8 秒一轮；角色选中状态、名字及外壳颜色仍使用原有独立设置。

## 接入

- `petRegistry.ts` 同时记录待机与移动的图集配置、循环图像和静态首帧；缺失动作继续退回 idle。
- `Pet.tsx` 统一显示动作和朝向，原生循环 PNG 避免给每只宠物叠加逐帧 JavaScript 定时器。
- `petRoaming.ts` 只处理视觉位置、休息和换向；不依赖真实额度、游戏计算或持久化。
- `usePetRoaming.ts` 管理活动生命周期、可见性与减少动态效果；`RoamingPet.tsx` 仅用于主页。
