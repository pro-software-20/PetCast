# B 模块 P2.7 端到端验收

日期：2026-10-25

## 验收范围

P2.7 验证任务分析、任务拆解、AI 推荐、工作区授权、人工执行、Codex 隔离执行、会话恢复和最终报告形成的完整 B 模块闭环。

验收脚本使用隐藏的 Electron 窗口、临时用户目录、临时项目和固定 IPC fixture。脚本拦截全部 HTTP/HTTPS 请求，不打开 OAuth 页面，不连接 DeepSeek、OpenAI 或真实 Codex，也不产生推理 Token。

## 验收中修复的问题

整页刷新时 React 的卸载回调不保证执行，可能导致 Renderer 已恢复为“需要人工确认”，但主进程中的 Codex prepare/run 仍继续。任务执行 IPC 现在监听可信 Renderer 的 `did-start-navigation` 和 `destroyed` 事件，主动取消准备或执行并清理资源；会话恢复继续作为第二层保护。

## 复现命令

```powershell
pnpm test:contracts

```

本轮契约测试为 365 项全部通过。`test:task-ui` 覆盖三条完整 UI 链路，并在结束时确认外部网络请求数为零。

## 人工视觉检查

- 任务分析面板在展开窗口中可以滚动，错误、加载和禁用状态可辨认。
- 工作区授权弹层不被任务卡裁剪，目录树、标签页和相对路径摘要可读。
- Codex 执行确认、diff、应用/丢弃和人工验收按钮顺序清晰。
- 地区限制或执行器不可用时，人工复制 Prompt 入口保持可见。

## 已知限制

- 本轮不进行真实 Codex、DeepSeek 或豆包调用；真实 OAuth 完整验收仍需在支持环境补测。
- 自动执行仅支持 Codex 的编程和测试任务，其他 Provider 保持人工复制。
- 不包含 Windows EXE、另一台电脑安装、A 额度专项或 D 报告页面专项验收。
- 启发式 Token 估算不是账单，也不会读取浏览器附件正文。
