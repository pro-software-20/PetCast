# 本轮 ImageGen 素材提示词设计规格

使用内置 ImageGen 工具，非 CLI/API 备用模式。以下归档可用于继续生成相同设计方向的素材。

## 横版河畔小屋

用途：PetCast 主页横版 3:2 游戏背景。参考已完成的温暖卡通小屋画风，奶油白、浅杏色、蜂蜜黄、浅木色，柔和低饱和。绘制一张平滑卡通插画：右侧小屋完整屋顶、圆窗、可点击房门与空白木质名牌，左侧和中央保留宽阔沙地作为宠物活动区域，河流横贯画面下部，清楚表现水岸边界。保留小屋温暖治愈的氛围与清楚的功能区域。不要绘制宠物、界面按钮、文字、Logo、水印、人物或额外统计图表；不要像素背景、写实、3D、霓虹色或复杂纹理。

输出素材：`public/assets/scenes/river-cartoon.png`。

## 四种原创鱼类透明图集

用途：PetCast 钓鱼、水族箱与图鉴。用户上传的像素鱼类图鉴仅作画风参考，创作独立原创造型，不复制已有鱼图。绘制四条完整、轮廓清楚的精致像素鱼，2×2 排列，彼此有足够透明留白：左上金色与奶油色的均衡锦鲤；右上紫色、细长弯曲的截止日期鳗鱼；左下海蓝色、具有月牙形鱼鳍特征的月鳍鱼；右下珊瑚橙粉色的重置鲑鱼。亲切休闲游戏像素氛围，低饱和、清晰阶梯边缘、各自可辨认。真实透明背景，不要棋盘格、文字、标注、边框、阴影底板、水印、人体肢体或其他鱼；保持每条鱼完整，不触碰彼此。导出带透明度的 PNG。

输出素材：`public/assets/fish/petcast-fish-atlas.png` 及按透明轮廓裁切的四个独立角色 PNG。鱼图只改变美术，不改变原有游戏规则。
