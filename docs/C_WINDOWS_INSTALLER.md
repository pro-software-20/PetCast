## 下载后怎么使用

1. 从 [GitHub 0.1.2 预发布](https://github.com/pro-software-20/PetCast/releases/tag/v0.1.2) 下载 `PetCast-Setup-0.1.2-x64.exe`；其他人不需要下载项目、安装 Node.js 或运行命令。
2. 先关闭正在运行的旧 PetCast，再双击安装包。
3. 选择安装目录，完成后从桌面 PetCast 快捷方式启动。
4. 更新或卸载时保留用户数据；安装版沿用 `%APPDATA%/petcast-stage1`，包括既有形象设置、游戏存档和历史记录。
5. 如需卸载，在 Windows“设置 → 应用”中找到 PetCast，或运行安装目录下的卸载程序。

软件内的宠物和外壳选择沿用用户保存的设置；安装图标不强制改变桌宠形象。

## 构建方式

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm dist:win
```

`pnpm dist:win` 先构建现有前端、主进程和服务代码，再使用 `scripts/package-windows.mjs` 准备独立应用目录并调用 electron-builder 26.18.0。实际桌面安装包仅包含前端、主进程、运行素材和生产依赖，开发服务仍独立部署。

每次生成新的 `release/staging-*/app`，使用真实文件收集生产依赖，避免把本机共享依赖目录链接交给接收者。准备目录声明独立的 npm 依赖布局，使打包器从此目录收集依赖，而不是回到开发项目的 pnpm 共享目录。输出包含安装 EXE、SHA256SUMS.txt 以及运行文件清单 package-manifest.json。

配置位于 `build/electron-builder.cjs`；`build/installer.nsh` 将安装模式限定为当前账号。`publish: never` 阻止构建时自动上传，内部包显式跳过签名。
