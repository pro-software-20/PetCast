## 启动与后续范围

直接双击项目根目录的 `启动 PetCast.lnk`。源代码改变后需先重新构建；开发环境可使用 `npm run build`、`npm start`。

本轮交付为界面整合、素材与可运行构建的源代码。独立安装包、另一台电脑验收、陆地动物行走帧尚未完成。依赖目录、构建产物、启动快捷方式、用户存档和登录凭据不纳入提交。

本机检查使用已有依赖与临时官方 npm 工具路径，执行 `pnpm typecheck`、`pnpm build`；临时关闭 pnpm 的运行前自动重装，避免重建现有共享依赖目录。团队其他成员正常克隆后仍按指南执行 `pnpm install`。
