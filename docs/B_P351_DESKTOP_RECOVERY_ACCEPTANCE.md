# B-P3.5.1 桌面端异常恢复验收

## 范围

`pnpm test:task-recovery-ui` 构建专用页面，在隐藏的 Electron 窗口中注入内存行为的 A 执行适配器。它使用临时用户数据和浏览器本地存储；测试进程拦截 HTTP/HTTPS，不调用真实 AI，也不产生模型费用。正式入口未注册该适配器。

## 验收场景

| 场景 | 页面检查 |
| --- | --- |
| 执行状态未知 | 点击“核对外部执行”，再“转人工处理”；可录入并保存人工结果，决定与会话状态一致，未重新派发。 |
| 人工接管后迟到的结果 | 重载并重新检查，旧执行的迟到完成结果不能覆盖人工接管决定。 |
| 派发中断、没有收据 | 新尝试需两次确认；确认后不立即派发，重载后仍暂停；用户重新启动才派发，且新尝试使用不同派发 ID。 |
| 查询发现执行完成 | 结果恢复到“待验收”，不自动验收或重跑。 |
| 限流与保存失败 | 显示等待建议；保存失败时不产生新尝试。 |
| 人工决定已保存、会话保存失败 | 重载后仍保持暂停；用户点击“立即检查”后从已保存的决定恢复新尝试状态，不重复派发。 |
| 损坏协调记录 | 原始记录保留，不自动删除。 |
| 活动执行证据 | 清空或重新分析不能静默删除协调记录和任务会话。 |

复现命令：

```powershell
pnpm test:task-recovery-ui
```

本验收只证明模拟适配器与桌面页面的交互。A 组通用真实 `ExecutionAdapter` 交付后，仍需在受控环境验证实际查询、取消、重复调用和费用记录。真实 D 评价与本测试的恢复操作相互独立。
